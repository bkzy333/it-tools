本目录下的 opencc-cn2t.js / opencc-t2cn.js 来自 opencc-js（开放中文转换 JavaScript 版）。

  上游仓库：https://github.com/nk2028/opencc-js
  包名与版本：opencc-js@1.4.2
  获取地址：https://cdn.jsdelivr.net/npm/opencc-js@1.4.2/dist/esm/cn2t.js
            https://cdn.jsdelivr.net/npm/opencc-js@1.4.2/dist/esm/t2cn.js
  本目录文件名：opencc-cn2t.wrapped.js / opencc-t2cn.wrapped.js
  许可证：MIT AND Apache-2.0
          —— 代码部分为 MIT（见下），随包分发的词典数据由 opencc-data 生成，为 Apache-2.0
             （https://github.com/nk2028/opencc-data）。
  改动说明：正文与上游**逐字符一致**，只做了一处结构性包裹 —— 把文件内容整体放进
            `function __openccFactory() { ... }` 内，并把原文末尾的 `export{a as B, ...}`
            改写为等价的 return + 具名导出（见文件开头注释）。
            原因：这两个文件是 minify 过的，顶层全是一两个字母的声明，打包器 rolldown
            在做 scope hoisting 时会因顶层重名报 `It can not be redeclared here`；
            包进函数作用域后这些名字不再参与顶层去重。脚本见 scripts/wrap-opencc.mjs。
